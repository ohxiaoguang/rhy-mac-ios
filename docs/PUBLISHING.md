## 提交检查

`.gitignore` 排除了常见本地文件。提交前检查暂存区，而不是只检查工作区：

```sh
git diff --cached --stat
python3 tools/check_source_release.py
```

该工具只检查 Git 暂存内容，拒绝资源目录、符号链接、二进制媒体、安装包、常见密钥/证书格式及可识别的密钥文本。它是防止误提交的技术辅助，不是完整的版权、许可证、秘密扫描或法律审查。
